# 知途 · AI 旅行与研学助手

把旅行期待变成每日安排，让地图连接每一站，让资料讲清沿途的故事。

知途支持多城市旅行规划、真实地图路线、全员预算、天气参考和 AI 行程调整，也提供带原文出处的上海历史研学与文字、照片问答。

![知途首页](docs/images/home.png)

## 1. 开始使用

知途在本机启动，通过浏览器使用。选择便携版或源码版，完成 API 配置后即可开始规划。

安装、配置和启动步骤请查看 **[安装与启动指南](docs/GETTING_STARTED.md)**。

## 2. 按自己的节奏规划旅行

填写出发地，按游玩顺序添加目的地，再设置出行日期、停留时间、同行人数、全员预算与旅行节奏。知途结合需求整理每日景点、餐饮、住宿建议和跨城交通，让安排落实到时间与地点。

可以粘贴已有攻略作为参考，也可以填写已确认的酒店、车票或机票。规划会结合酒店位置和已订交通时刻安排接驳，并将填写的费用计入预算。

铁路查询成功时展示实际车次、时刻和参考票价；其他交通信息按取得的数据标明查询结果或估算依据。

![旅行规划设置](docs/images/travel-planner.png)

## 3. 在地图上查看路线，算清全程费用

每日活动与地图联动，选择地点即可查看位置，切换日期即可查看当天路线。通过“比较交通”查看步行、公交／地铁、打车、自驾和骑行的可用方案，比较耗时、距离与全员费用，再预览确认交通调整。

预算按全部同行人的整趟费用汇总，分别展示景点门票、餐饮、住宿和交通。展开明细可以查看金额、数量、计费人数及参考依据；未取得的价格或路线会保留待核实说明。

## 4. 用对话调整，确认后再保存

打开“调整行程”，直接描述想增加、删除或替换的安排，例如：

> 把第二天下午改为外滩漫步两小时，减少步行，保留已订酒店。

AI 根据对话修改安排，系统核对相关地点与路线，重新计算时间和费用，并展示修改预览。确认后保存为新版本，原方案继续保留，方便查看和比较。

已订酒店、交通、已完成安排和已付费用会受到保护。补录酒店与交通时，同样可以先查看接驳和预算变化，再决定是否保存。

## 5. 沿着资料开展上海历史研学

历史研学模块使用 RAG 检索原文，将历史问题与城市地点连接起来，为每站提供选择理由、资料线索和现场观察问题。

当前演示使用 **20 篇上海图书馆开放数据平台的历史地点资料，仅支持上海单日研学**。可围绕青年与新思想、书刊出版、文学旧居、城市建筑和抗战记忆等主题展开。页面可展开查看全部资料标题，讲解中的引用可用于核对原文与来源。

历史记载与当前参观安排分别呈现：资料用于理解历史，开放时间、预约和购票信息可通过出行参考查询。资料集附带许可说明，许可文件不进入研学检索范围。

## 6. 用文字和照片追问沿途故事

在资料问答中询问人物、事件与地点的联系，也可以结合上一轮回答继续追问。上传或粘贴照片后，可根据建筑、铭牌或展品等图片线索获取讲解，并查看回答所依据的资料或网页来源。

文字与照片问答保留会话记录，便于回看和继续讨论。

![历史研学与问答](docs/images/study-and-qa.png)

## 7. 查看天气，按需查询出行参考

规划时结合目的地天气，行程按城市和日期展示预报、温度、风力与发布时间。预报尚未覆盖的日期会明确标注，历史版本保留当时的天气快照。

选中行程中的景点后，可主动查询出行参考，包括四个栏目：

- 景点简介与推荐看点。
- 购票、预约与开放时间。
- 怎么参观。
- 实用提醒。

查询结果附带网页来源和查询时间，已保存的攻略可以再次查看。出行参考供准备旅程使用，不会自动修改行程。

## 8. 保存自己的旅行记录

行程、版本、已保存攻略和问答会话保存在本机。可以从“我的行程”打开已有方案，继续查看、调整或删除所选版本。

模型、地图、天气和联网查询功能需要有效的服务配置与网络连接。票价、开放时间及天气会变化，出发前请核实；费用估算供预算参考，知途不代订酒店或车票。
