# 知途 · AI旅行与研学助手

把想去的城市、可用时间和预算告诉知途，获得一份可以在地图上查看、随时调整的旅行计划。也可以从一个历史问题出发，沿着人物、书刊与城市旧址，安排一段有出处、有观察任务的研学旅程。

![产品首页：普通旅行与历史研学两个入口](docs/images/home.png)

## 1. 多城市旅行规划

一次旅行可以按顺序添加1–5个目的地，为每座城市设置停留时间，再填写日期、同行人数、全员总预算与旅行节奏。知途会结合这些需求，整理每日景点、餐饮和住宿片区建议，将分散的旅行想法串成完整安排。需要从出发地前往首城或最后返回时，可以在生成前勾选对应交通选项，一并纳入规划。

已有收藏的攻略也能派上用场。将攻略正文粘贴进来，可以优先参考其中的地点、顺序和玩法，也可以只把它作为灵感；结果中能够查看攻略与活动的对应关系，以及调整或未采纳的原因。

![普通旅行设置：目的地顺序、停留时间与出发返程选项](docs/images/travel-planner.png)

## 2. 地图路线与全员预算

每天的安排通过时间线与地图联动展示。切换日期查看当天路线，点击地点定位对应位置，也可以比较步行、驾车、公共交通、骑行与打车等方式，按需要逐段切换。跨城行程单独展示交通安排；铁路查询成功时，可以查看车次、席位和参考票价。

旅行预算按所有同行人的全程费用汇总，分别展示餐饮、住宿、交通和景点门票等项目，并可展开查看费用组成与计算依据。所选出发、跨城和返程交通也参与统计；超预算或费用缺项会明确提示，便于判断是调整景点、交通方式，还是重新分配预算。餐饮、住宿及未取得实际报价的项目保留估算说明。

## 3. 围绕历史问题的研学

选择“历史研学”，从一个想了解的问题出发，知途会从原文中检索线索，将人物、事件和今天能够走近的地点联系起来。每站除了参观安排，还包含“为什么选这里”“资料里的线索”和“现场想一想”，把阅读资料、实地观察与思考连接起来。

讲解附带资料出处，可以打开对应原文核对和延伸阅读。当前资源包含19篇上海近代历史资料，支持上海单日走读，适合探索青年与新思想、书刊翻译出版、城市红色记忆等主题。例如：**“1920年前后的上海：青年与新思想”**。

## 4. 文字与照片讲解

在“问问沿途的故事”中，可以询问人物、事件和地点之间的联系，并接着上一轮内容继续追问。回答分别保留资料出处，对话记录可以恢复，适合在规划前了解背景，也适合参观过程中边走边问。

遇到感兴趣的展品、建筑或铭牌，可以上传或粘贴照片，结合现场对象与相关资料获得讲解，再追问某个细节。支持3MB以内的JPG／PNG图片，预览后手动发送；清晰的对象和文字有助于获得更有针对性的解释。资料问答与照片提问独立于行程调整，不会改动已安排的旅程。

![历史研学与问答入口：选择主题、文字提问及添加照片](docs/images/study-and-qa.png)

## 5. 天气与地点出行参考

生成或修改行程时，知途会查询目的地天气，供安排活动时参考。每日行程展示对应城市和日期的预报，并提供出行建议；多城市旅行分别匹配各地天气。需要时可以手动重查，查看最新天气，历史版本仍保留当时的天气信息。

想进一步了解某个地点，可以在“出行参考”中选中它，再主动查询。结果按“景点简介与推荐看点”“购票、预约与开放时间”“怎么参观”“实用提醒”四个栏目整理，并附来源链接。已保存的攻略可直接查看，需要最新信息时再点击更新，查询结果不会自动改变原行程。

## 6. 自然语言调整与历史版本

计划生成后，可以直接描述想改的地方，例如“第二天少安排一个景点，多留些休息时间”。普通旅行支持修改整个行程或仅修改当前一天；历史研学可以调整可用时间、保留喜欢的地点，或改变讲解重点。

生成的行程自动保存在“我的行程”。活动修改会创建新版本，方便比较前后安排；仅刷新路线或切换交通方式时，更新当前版本。更改表单中的出发、返程等选项后，需要重新规划，才会更新已显示的交通与预算。

## 7. 开始使用

推荐使用便携版，解压后填写 API 配置即可启动；也可以选择源码版安装。两种方式的详细步骤见[安装与启动指南](docs/GETTING_STARTED.md)。
