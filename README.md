# 知途 · AI旅行与研学助手

把目的地、时间和预算告诉知途，获得一份可以在地图上查看、按实际情况调整的旅行计划。也可以从历史问题出发，沿着有资料出处的城市地点开展研学。

## 1. 开始使用

可选择 Windows 便携版或源码版。填写根目录的 `.env.local` 后启动，详细步骤见 **[安装与启动指南](docs/GETTING_STARTED.md)**。

![知途首页](docs/images/home.png)

## 2. 多城市旅行规划

按顺序添加目的地，设置停留时间、出发日期、同行人数、全员预算和旅行节奏，生成每日活动与跨城安排。收藏的攻略可以作为规划参考，已有酒店、车票或机票也可填写为固定条件。

铁路查询成功后展示车次、时刻与参考票价；跨城交通可结合距离、时间和费用提供方式建议。飞机方案使用估算信息，系统不提供实时航班查询或代订服务。已订交通按填写的实际时刻与费用参与安排。

![旅行规划设置](docs/images/travel-planner.png)

## 3. 地图路线与费用预算

每日活动与地图联动，点击地点查看位置，切换日期查看当天路线。展开“比较交通”，可比较步行、公交／地铁、打车、自驾与骑行的耗时和全员费用；查询或预览后，可在调整行程中确认采用。

预算按同行人的全程费用汇总，分别展示门票、餐饮、住宿和交通。费用明细说明参考数据与计算方式；已订总额不会再按人数或夜数重复计算。未取得的内容会标明待确认。

## 4. 先预览，再调整行程

描述希望修改的内容，或在“调整行程”中设置活动优先级、可用时间、交通方式和预算，先查看调整结果，再确认保存。已完成活动与已订安排受到保护，途中漏游的地点也可尝试重新安排。

行程保存在本机，可查看历史版本。补录酒店与已订交通时，能够先预览接驳、费用和时间变化；取消操作保留原方案。历史研学采用独立的资料引用与调整流程。

## 5. 有出处的上海历史研学

历史研学模块通过 RAG 检索原文，连接人物、事件和今天可以走近的地点，为每站提供资料线索与现场观察问题。当前演示使用20篇上海图书馆历史地点资料，仅支持上海单日研学，可围绕青年与新思想、书刊出版、文学旧居、城市建筑和抗战记忆展开。

引用附有资料出处，便于核对与延伸阅读。历史记载不代表场所目前开放或允许入内，参观前仍需核实。统一许可说明随资料集保存，不参与研学检索。

## 6. 文字与照片问答

在“问问沿途的故事”中询问人物、事件和地点之间的联系，也可以继续追问。上传或粘贴照片后，可结合现场建筑、铭牌或展品获取讲解。文字与照片问答保留资料来源及会话记录，不会自动修改旅行安排。

![历史研学与问答](docs/images/study-and-qa.png)

## 7. 天气与出行参考

按城市和日期查看天气，必要时主动更新。选中行程地点后，可查询景点介绍、推荐看点、购票预约、开放时间及实用提醒，并查看网页来源。出行参考支持公开网页检索，查询结果供出行准备使用，不自动改变行程。
