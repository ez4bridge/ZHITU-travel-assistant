# 行程调整进程协议 2.2

进程接收 `repair` 或 `evaluate` JSON 请求，输出候选安排、差异、未安置活动、费用、检查项与搜索终止原因。输入金额为整数分，日索引为本次窗口的0—2。可运行协议样例位于 `fixtures/cases.json`。

支持 `walking`、`taxi`、`driving`、`transit`、`bicycling`，仅使用请求中提供的路线和费用，不联网补充数据。未知费用、开放时间和路线不得视为免费或已核实。

搜索上限为200个状态和2000毫秒；进程边界限制总执行时间5秒、输入与标准输出各1MB、标准错误64KB。有限搜索没有找到候选，不代表已证明全局无解。

`backend/constraint_reference.py` 独立重算身份、时间、保护条件与费用，不参与搜索。上层适配器同时复核完整旅行的跨城交通、酒店、总费用及未选日期，预览须经用户确认后保存。

源代码适用根目录 Mulan PSL v2 许可。运行文件及构建说明见[模块说明](../README.md)。
