# 当前实现介绍

源码核对：2026-10-15。此前运行验收：2026-10-14，详情见 [验收记录](ACCEPTANCE.md)。本文介绍当前代码实现。

## 现在可以完整体验什么

用户输入目的地城市、日期、天数、人数、全员预算、节奏、步行/驾车与偏好 → Agent 查询高德 → 输出结构化行程 → 服务端核对地点和路线、计算费用、执行规则 → 保存版本 → 页面展示每日活动、地图、预算和问题 → 用户提出一次修改 → 保存新版本并保留旧版。

| 功能 | 当前实现 |
|---|---|
| 需求表单 | 单目的地城市，1–10 天，1–50 人，起始时间、偏好、3 种节奏；出发地作为规划背景 |
| Agent | LangGraph 工具调用循环；工具结果返回模型，再输出 JSON |
| 地点核实 | 目的地城市限制搜索、POI ID/名称匹配，使用查询得到的坐标；查不到时标为未知 |
| 路线 | 高德真实步行/驾车距离、时长、道路形状，查询当日相邻活动之间的路线 |
| 费用 | 元输入，Python Decimal 按单位/数量/人数计算，整数分汇总；全员全部天数预算，价格标为估算 |
| 校验 | 超预算、时间不合法/重叠、转移不足、重复景点、日期与缺项；营业时间和预约列为待确认 |
| 行程修改 | 每次点击执行一轮、沿用原需求，保存新版本和修改后的校验结果 |
| 地图与时间轴 | 日切换、地点选择联动、真实路线绘制；坐标 GCJ-02 |
| 历史 | SQLite 最近 50 条摘要、读取完整版本、父版本关联；数据保存在本机 |
| 取消 | 浏览器 AbortController，服务端取消进行中的任务并关闭客户端 |
| 仓颉 | 已实际编译的规则校验器，JSON stdin/stdout，Python 自动回退 |

## 技术分别负责什么

- **Vue 3 / TypeScript / Vite**：页面、交互、类型检查、开发热更新和构建；自定义 CSS、Lucide 图标、原生 SVG 城市插画。
- **FastAPI / Pydantic 2**：HTTP、请求/输出数据结构、SSE 与同源静态页面。
- **LangGraph / OpenAI 兼容客户端**：管理消息与轮次，调用模型和本地 Python 工具。
- **HTTPX / 高德 REST 与 JS SDK**：城市地点、道路数据、底图；Web 安全密钥通过受限代理在服务端注入。
- **Decimal / Python / 可选仓颉**：费用和可重复的规则判定；大模型不负责最终算账和判定“通过”。
- **SQLite**：在本机保存完整 JSON 版本。

## 代码入口速查

| 文件 | 改什么时找它 |
|---|---|
| `backend/models.py` | 请求、行程、费用、路线、报告、历史完整记录 |
| `backend/agent.py` | 提示词、search_places/get_route 工具声明、循环与 JSON 修复 |
| `backend/amap.py` | 签名、查询、POI 匹配、道路路线、最终定位和补充 |
| `backend/validation.py` | 规范化、Python 规则、仓颉一致性与回退 |
| `backend/main.py` | API、SSE、取消、静态页面、地图代理 |
| `backend/storage.py` / `config.py` | 版本数据库 / 本地设置与脱敏 |
| `frontend/src/App.vue` / `style.css` | 主要界面状态与布局；目前仍集中，不要多人同时整体重写 |
| `frontend/src/types.ts` / `api.ts` | 前端契约 / 普通请求与流解析 |
| `frontend/src/components/RouteMap.vue` | SDK、标记与路线、地图生命周期 |
| `cangjie/src/validator.cj` | 可选仓颉 JSON 编解码与规则 |
| `tests/test_core.py` | 核心行为、异常与部分原生仓颉测试 |

Agent 最多 8 轮，每轮至多执行 6 个工具调用；模型单请求超时 60 秒，高德 15 秒，整次生成/修改 180 秒，结构化 JSON 只修复一次。仓颉子进程上限 3 秒。这些限制均来自当前实现，改动时同步说明。

## 运行方式

服务默认监听 `127.0.0.1:7862`。GitHub 分享代码，其他成员各自运行；本机数据库与配置单独保存在各自电脑中。
