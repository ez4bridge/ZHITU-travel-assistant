# 当前实现

## 功能范围

Windows 本机旅行规划原型，使用 Python + FastAPI + LangGraph、Vue 3 + TypeScript + Vite，数据保存在本机 SQLite。支持中国境内 1–5 个目的地、1–10 天和 1–50 人；完整安装步骤见 [运行教程](GETTING_STARTED.md)。

| 功能 | 当前行为 |
|---|---|
| 需求输入 | 可选出发城市、逐城游玩天数、日期、首日时间、人数、全员预算、节奏与偏好；按需显示跨城偏好，支持出发及返程 |
| 地点核实 | 按活动城市查询真实 POI，活动标题与检索名称分开，模糊分店不直接取首项；模型坐标不作为证据 |
| 区域游览 | 从地图真实子地点或明确入口选通勤点，过滤无关设施；刷新保留已核实点，不以区域中心冒充具体餐馆 |
| 市内交通 | 比较步行、自驾、公交地铁、骑行、打车的真实路线，默认按接口耗时选最快可用方式，保留逐段手选；打车复用驾车路网 |
| 餐饮与住宿 | 用真实道路距离筛选顺路餐馆，优先特色菜及攻略推荐；尽量按常见饭点安排，无餐提醒沿途就餐或自带干粮；未确认酒店只推荐片区 |
| 地点费用与营业 | 费用关联活动且仅记账一次；展示有来源与查询时间的地图营业参考，区分区域与地点，平均消费不冒充门票 |
| 交通预算 | 展示地图票价／出租车估价、地区公开费率或明确假设的参考区间；按人数／车辆用 Decimal 汇总到分，未知不当免费 |
| 跨城与铁路 | 独立展示跨城段；内置固定 12306 MCP 源码及数据，setup 默认安装独立依赖；可查直达时刻、席位快照及公布参考价，失败保留估算 |
| 攻略参考 | 最多3篇正文，自动编号；可优先地点与顺序或仅作灵感，展示原文、对应活动及调整／未采纳原因，程序复核关联 |
| 校验与修改 | 检查日期、冲突、真实通勤、城市顺序、预算和费用缺项；关键地点／路线缺失阻断；有界调整时间，支持只改当天 |
| 历史与操作 | 活动修改保留新版本；交通切换及活动不变的刷新更新原记录，使用修订号防并发覆盖；支持单版本删除、取消及超时 |
| 运行诊断 | health 提供源码指纹、任务统计和脱敏失败阶段；按接口共享限速并有限重试，start 检测旧进程，restart 核验后重启 |

## 运行与兼容

- 服务默认仅监听 127.0.0.1:7862，保留 Host/Origin 限制；单进程最多两个规划任务。当前不具备公开多人服务的账号及数据隔离。
- 主应用 .venv 与铁路 .tools/rail-mcp/.venv 独立。源码随仓库提供，依赖需安装；已有 .env.local 不覆盖，是否启用由本机配置决定。见 [铁路说明](RAIL_MCP.md)。
- 旧行程通过默认字段兼容，不自动重写。更新地图信息可刷新；攻略与特色菜的整体调整需重新规划。重新校验不联网、不改历史。
- 日期、金额、坐标、SSE 及公共字段见 [接口约定](API_CONTRACT.md)；模块职责见 [架构](ARCHITECTURE.md)。

## 本版更新

- 费用统一由后端账本汇总，明细、分类和总额使用同一组金额；修正按人门票重复乘人数、餐饮与地图人均参考不同步的问题。预算小窗按天／跨城分组，展示单价、次数、人数、小计和依据；旧记录可原地核对费用，超支可由用户发起一轮重排。
- 区域餐饮与区域游览共用真实子地点／入口／地标作为通勤锚点，明确是区域自选用餐而非已确认餐馆。查不到关联真实点时保留未知，区域平均消费不作为餐费。补全区域锚点而活动不变时更新原记录。
- 同轮独立地点查询并行、重复检索合并；交通比较不再重复进行串行步行预查，五种方式仍查询真实接口，QPS限制不变，铁路stdio查询仍串行。
- 模型请求不继承系统代理；流式接收并关闭网关思考输出，记录脱敏阶段耗时。错误区分模型访问拒绝、读超时、格式错误与地图限额；不展示原始HTML或推理内容。
- 四天及以上先确定全程框架，再每两天分批细化，最多两批并行。支持非相邻城市回访、纯交通日和往返出发地；结构／长度失败复用资料有界回退，取消时回收其他批次。按规模分配阶段时限，整次最多900秒，不保存半成品。
- 铁路选中车次也必须复核活动时间窗口与到达城市顺序，不因来自真实查询就忽略与行程的冲突。

## 已知限制

- 长途往返会占用总天数，各城期望游玩时长与交通、总天数可能无法同时满足；分批生成不能保证消除所有跨城／活动冲突。现有校验会继续报告问题，不保证任意输入都能生成可执行方案，五城十天尚无完整真实接口验收。
- 地点和路线依赖高德返回，只做局部顺路优化，不保证全局最短；区域锚点不代表区域内完整步行距离。地图营业参考不保证旅行日开放、预约或商家营业，未知地点／路线不以虚构数据补齐。
- 门票、餐饮及其他支出仍是参考估算；地图人均消费不是菜单报价，门票估算不是官方核实票价，预算不是成交承诺。交通未知费用不当作免费。
- 铁路只查询直达时刻、席位快照和公布参考价，不能订票／锁价；未开售、查询失败或时间不适配时保留估算和原因。无机票实查、铁路换乘查询或官方预约库存核验。
- 攻略需用户粘贴正文，展示实际关联与采纳原因，不自动抓取小红书。攻略事实未经独立核实，不作为营业、政策或预约保证。
- 当前是本机原型，不具备公开多人服务所需的账号、权限及数据隔离。
