# 餐饮、住宿、交通保存与费用修正

对应实际北京 10/28 行程：颐和园 → 菜市口午餐 → 圆明园的餐饮折返问题，以及交通切换产生连续存档的问题。

## 变更明细

1. 餐饮：模型提示要求相邻景点就近用餐；服务端对明显绕路的中间餐饮，用高德实际驾车道路距离核对。调用 `/v3/place/around` 查询相邻真实景点周边 1200 米的餐饮 POI，最多验证 3 个候选；只替换道路距离明显缩短、相对直接路线增加不超过 2500 米的选项。坐标距离仅作候选预筛，绝不展示为导航距离或换算耗时。用户明确点名的餐厅保留；核验失败提示待调整，不编造替代。
2. 住宿：`confirmed_hotel` 留空时移除模型酒店活动，推荐住宿片区，不把助手推荐的某家酒店固定为起终点。未确认酒店的接驳不纳入路线，并明确提示。用户填入已确认酒店后才按该酒店安排接驳；住宿费用仍是预算参考。
3. 保存：逐段交通选择直接更新当前记录，id、parent_id、revision、created_at 不变；`routing_revision` 递增并防止多页面覆盖。活动时间从 `schedule_baseline` 重排，避免切换后不断顺延。更新路线时活动结构不变也沿用当前记录；修改活动或替换餐厅、移除酒店活动才保留原方案并生成新版本。旧交通切换产生的相同结构祖先从列表折叠，原始记录不删除，仍可按 id 读取。
4. 费用：交通显示元/人或元/辆的参考区间、计算假设和来源；全员预算取各段上限，普通车按每车最多 4 人计车辆数。自驾估算道路里程对应的油费、目的地停留对应的停车预算和接口返回的过路费，不含租车押金等。燃油 6–10L/百公里、8–9.5元/L 是明确的预算假设，不能称实时油价。北京停车引用公开路侧标准，其他城市未收录时显示通用预算假设。
5. 数据来源：步行 `/v3/direction/walking`，自驾及打车 `/v3/direction/driving`，公交 `/v3/direction/transit/integrated`，骑行 `/v4/direction/bicycling`。距离、耗时、道路折线均来自接口；无完整道路形状仍不可用。驾车补传 `extensions=all`，解析 `route.taxi_cost`、`path.tolls`；打车使用驾车路网，不含候车，不冒充网约车实时报价。接口缺失出租车估价时，北京/上海采用注明日期的公开费率参考；其他城市用明确预算假设。骑行参考共享单车使用费，同时说明自带车使用费为 0。历史记录缺少接口来源字段时不伪造查询来源，刷新后才记录。
6. 界面：保留原有布局和配色，新增活动说明 11px、费用/来源等辅助文字 9px、表单输入 13px，与原设计对应元素一致。费用依据和长说明在原有交通展开区中展示，默认保持紧凑。

## 来源与边界

- [高德路径规划文档](https://lbs.amap.com/api/webservice/guide/api/direction)：路径、耗时、公交票价、出租车估价与过路费字段；当前未接入网约车订单实时询价。
- [北京巡游出租车标准（2023公开信息）](https://jtw.beijing.gov.cn/czqc/zxts/202303/t20230310_2933641.html)、[上海出租车运价](https://jtw.sh.gov.cn/czqcyj/index.html)：缺失高德估价时的参考，不保证出行日费率，等候等费用未计。
- [北京路侧停车公开标准](https://jtw.beijing.gov.cn/qaknowledge/202204/t20220426_2692780.html)：不能当作某个景点停车场报价。
- [北京时间转北京日报2026年6月单车调价报道](https://item.btime.com/f32s19nb9ns8n19b9rshfrkqlgj)：北京共享单车参考费率；实际以扫码页运营区、车型、活动价格为准。

餐厅营业、景区预约、实际停车位置、酒店接驳和未来出行日票价仍有待确认项。没有接入实时报价的部分明确叫参考/假设，不伪装为高德返回。同名地点只在唯一明确的景区类型可区分于道路时消歧，餐馆分店仍不随意选择。短途公交确实无方案时，推荐接口核实成功的 ≤1500 米步行并明确说明原因，不会用假路线填补公交。新业务检查进入共享规范化输入的 warnings/unknowns；Python 与仓颉消费同一输入，核心协议未改变。
